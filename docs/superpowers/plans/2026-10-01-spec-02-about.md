# Spec 02 About Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to run this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/about` per spec 02. Sections that need content the club hasn't supplied stay hidden until it exists.

**Architecture:**
- `content/about.ts` and `content/timeline.ts` hold typed content.
- `lib/about.ts` holds pure helpers: visibility, sorting, and the partner count used by Home. `lib/validate-about.ts` validates at build time.
- `components/about/*` are server components composed by `AboutPage`, so they can be tested with fixtures.

**Spec:** `docs/specs/02-about.md`. It depends on spec 00, and on spec 01 §5 for the Apply band.

## Global Constraints

- Spec 00 tokens only. Exactly one `h1` and one navy band.
- Nothing is fabricated. The founding story, partners and advisors render only from real content.
- Section numbers are sequential over the sections that render.
- Partner names are text only (no logos). External links open in a new tab with `rel="noopener noreferrer"`.

## Decisions filling gaps in the spec

- "Our story" is hidden when there are no paragraphs and fewer than 3 milestones. `paragraphs` must have 0 or 2–4 entries, and a quote requires paragraphs.
- The pull quote sits next to the second and later paragraphs on desktop. The first paragraph gets its own row, so the quote lines up with the top of paragraph two, as the spec intends.
- Mission and vision statements, the principles, and section headings ship as working copy (spec 02 §3), editable in `content/about.ts`.
- Home's partner stat is `home.stats.partnerFirms ?? (about.partners.length || undefined)`, so zero partners still means no stat.

3. **Components and route:**

   - Fixture-based page tests.
4. **Verify:** typecheck, lint, test, build; browser check at 375, 768 and 1280; Lighthouse.
