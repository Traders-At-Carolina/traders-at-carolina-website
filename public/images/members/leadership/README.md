# Members — leadership

Headshots for the executive board (Members page, "Executive board.").

- Square (1:1), at least 800x800, JPG.
- Head-and-shoulders framing, face centred, consistent across the set.
- Naming: `firstname-lastname.jpg`, lowercase and hyphenated.

Reference each file from the `photo` field in `src/data/members.json`, e.g.
`"/images/members/leadership/jane-doe.jpg"`. An empty `photo` shows a blank
block, never a broken image.
