# Placement

Firm logos for the "Where our members go" section.

- SVG, or PNG with a transparent background.
- Single-colour / monochrome marks read best.
- Target ~40px rendered height, so supply at least 200px wide.
- Naming: lowercase, hyphenated, e.g. `jane-street.svg`.

While this folder is empty the homepage shows a blank #EBEAE4 block in place of the grid. Logos are added by registering them in the `placementLogos` array in `src/home/HomePlacement.tsx`.
