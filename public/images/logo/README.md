# Logo

Club logo marks used in the site nav and hero.

- `logo-mark.svg` — the square club mark, used in the nav at 36px. Dark/navy version, for use on white.
- `logo-mark-white.svg` — the same mark in white, used in the hero at 88px on the navy overlay.
- SVG preferred. If raster, supply at least 512x512 PNG with transparency.
- Square aspect ratio (1:1), with the artwork trimmed to the edges of the canvas.

**Note:** the two SVGs currently in this folder are neutral placeholders so the nav and hero render without broken images. Replace both with the real Traders at Carolina logo, keeping the same filenames.
