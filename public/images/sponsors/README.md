# Sponsors

Sponsor logos for the Sponsors page.

- SVG, or PNG with a transparent background, at least 400px wide.
- Logos render inside 288x180 tiles with ~32px padding (`object-fit: contain`).
- Use the sponsor's approved logo files only; do not recolour, crop, or distort them.
- Naming: the sponsor's slug, lowercase and hyphenated, e.g. `acme-capital.svg`.

Reference each file from the `logo` field in `src/data/sponsors.json`, e.g.
`"/images/sponsors/acme-capital.svg"`. An empty `logo` shows a blank tile.
